主题一键出短视频

输入一个主题或关键词，自动写视频文案、配音、配字幕和背景音乐、匹配素材，合成竖屏或横屏的短视频成片。

怎么用

  1. 下载 portable.zip 解压到路径里没有中文和空格的文件夹，双击启动脚本
  2. 第一次启动自动安装依赖（约 700 MB），完成后浏览器自动打开 http://127.0.0.1:8501
  3. 在「基础设置」里填自己的大模型接口密钥和素材来源（Pexels / Pixabay 或本地素材）
  4. 输入主题，选择画面比例和配音，生成视频
交付形式　启动器 portable.zip，在浏览器里操作；密钥只保存在本机 config.toml
